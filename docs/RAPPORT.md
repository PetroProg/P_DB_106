## Les données de l'aéroport

**Table Aéroport:**
Code IATA et ICAO:

* IATA => 3 lettres (Code n'est pas unique)(CDG --> Paris Charles de Gaulle)
* ICAO => 4 lettres (Système aérienne; pour CDG --> LFPG)(Code est unique)

Chaque aéroport a le nom officiel

**Table compagnie aériennes**
Code IATA => 2 lettres (AF --> Air France)
Elle a le nom officiel
La compagnie est associée à l'aéroport
